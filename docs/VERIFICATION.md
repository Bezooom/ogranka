# Проверка стенда

Дата прогона: 2026-11-14. Машина: Linux, x64. SDK: .NET 10.0.115. Рантайм на стенде: только `Microsoft.NETCore.App 10.0.15`. Таргет `net48` собран через compile-time пакет `Microsoft.NETFramework.ReferenceAssemblies.net48` 1.0.3. Tekla Structures на стенде не установлена.

Команда:

```bash
dotnet build -c Release
dotnet run -c Release -f net10.0 -- --self-test
dotnet build -c Release -f net48
```

`dotnet build -c Release` собирает оба таргета. `--self-test` гоняет гейты, пишет `test_output.stp` и `test_concave.stp`. Образцы того же вида лежат в [`samples/`](../samples).

Путь к скриншотам не входит в `--self-test`: образцы рендерил отдельный сеанс GUI FreeCAD. Команда и лог сохранены в истории задачи, а не в репозитории.

## Что в образцах

`samples/i-beam-web-hole.stp`:

- схема `AUTOMOTIVE_DESIGN`;
- единицы `( LENGTH_UNIT() NAMED_UNIT(*) SI_UNIT(.MILLI.,.METRE.) )`;
- `MANIFOLD_SOLID_BREP('I-beam-web-hole', #closed_shell)`;
- `ADVANCED_BREP_SHAPE_REPRESENTATION`, первый item – `AXIS2_PLACEMENT_3D`;
- отверстие в стенке записано как `FACE_BOUND`, не как отдельное тело.

`samples/l-cut-box.stp` – тот же писатель после вогнутого выреза: 50 граней, одна замкнутая оболочка, `MANIFOLD_SOLID_BREP`.

## Чего этот прогон не доказывает

- Не было файла IFC, выгруженного Tekla. Фикстуры написаны вручную под IFC2x3.
- Ветка `#if TEKLA` не компилировалась: на стенде нет `Tekla.Structures.Model.dll`.
- `--live` не вызывал `GetSolid()` у выбранной балки, пластины, полибалки или сборки.
- Вогнутый инструмент вычитается только когда он экструзия, проходит тело насквозь, ось совпадает с нормалью профиля и в профиле нет отверстий. Иначе – предупреждение и первый операнд без выреза.
- Невыпуклый `IfcFacetedBrep` как инструмент булевой операции не вычитается: mesh-CSG не реализован, пишется предупреждение.
- Дуги в STEP – ломаные: 8 сегментов на четверть для филлетов, 32 станции для вращения и диска. Аналитических `CIRCLE` в файле нет.
- Замкнутая направляющая `IfcSweptDiskSolid` строится с кольцами по биссектрисе угла, поэтому на углах 90° труба короче прямой: объём 70.7 % от «площадь × периметр». Тело при этом замкнуто.
- Отгибы C-профиля строятся только при `Girth` больше `WallThickness` и меньше половины глубины минус стенка; иначе профиль пишется без отгибов с предупреждением.
- `IfcArbitraryClosedProfileDef` не имеет своего Position: смещение задаётся только Position у `IfcExtrudedAreaSolid`.
