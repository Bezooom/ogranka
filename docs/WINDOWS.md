# Следующий стенд: Windows с Tekla

На стенде разработки Tekla не было. Этот файл — протокол, а не отчёт о пройденной проверке. Пока пункты ниже не закрыты числами, `--live` считается непринятым.

Wine не является планом проверки. Tekla Structures — нативный CAD с .NET Framework и собственным IPC. Официально он работает только в Windows. Виртуалка имеет смысл, только если своей Windows-машины с лицензией Tekla нет. Если Tekla уже стоит на рабочей станции, виртуалка не нужна: достаточно скопировать туда `bin/Release/net48/TeklaToStep.exe`.

## Что копировать

Предпочтительно собрать на самой Windows-машине:

```bat
dotnet build -c Release -f net48
bin\Release\net48\TeklaToStep.exe --help
```

Готовый exe со стенда Linux тоже framework-dependent под .NET Framework 4.8 x64. Рядом с ним нет DLL Tekla, и это нормально: резолвер ищет их в каталоге открытого Tekla.

Если при сборке на Windows в каталоге Tekla найден `Tekla.Structures.Model.dll`, проект определяет символ `TEKLA` и включает типизированный путь. Эта ветка на Linux не собиралась. Первая такая сборка сама по себе является проверкой: она должна пройти без ошибки компиляции.

## Протокол `--live`

Модель Tekla открыта. В выборке по одному объекту каждого типа, который есть в модели.

| Объект | Команда | Приёмка |
| --- | --- | --- |
| Балка | `TeklaToStep.exe --live beam.stp` | файл создан, код 0, в stderr нет «не дал Solid» |
| Контурная пластина | то же | оболочка замкнута: свой гейт или импорт без ошибки |
| Полибалка | то же | есть грани, нет пустого Solid |
| B-rep / элемент с вырезом | то же | отверстие не исчезло и не удвоилось |
| Сборка | то же | в STEP больше одного `MANIFOLD_SOLID_BREP`, если в сборке несколько деталей |
| Ничего не выбрано | то же | код 2, текст «ничего не выбрано» |
| Tekla закрыта | то же | код 2, текст «не подключена», без необработанного исключения |
| Ссылочная модель целиком | то же | предупреждение, а не падение |

Если exe запущен не из каталога Tekla, передать `--tekla-bin` на `...\bin`, где лежит `Tekla.Structures.Model.dll`.

## Протокол `--ifc`

Взять реальный экспорт Tekla, не фикстуру из репозитория.

1. IFC2x3 Coordination View, балка и пластина с отверстием.
2. Тот же набор в IFC4.
3. Файл, где единицы — метры, если такой экспорт включён. Ожидание: координаты в STEP в миллиметрах, габарит не в 1000 раз меньше.
4. Сравнить число тел и имена с деревом IFC. Пропущенный тип должен быть строкой предупреждения, не молчаливой потерей.

## Импорт STEP

Один и тот же `samples/i-beam-web-hole.stp` и один файл из `--live` открыть в том, что есть на станке: FreeCAD, SolidWorks, Inventor, Rhino. Для каждого записать:

- открылся или код/текст ошибки;
- единицы: 300 мм по длине двутавра, не 300 м и не 0.3 мм;
- одно тело, отверстие сквозь стенку, не отдельный параллелепипед;
- масса или объём, если CAD её считает: для образца ожидается 1 123 200 мм³ стали только как геометрический объём, не как масса.

Импорт, который не запускался, в отчёт не записывать как успех.
